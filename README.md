# 締切まとめ通知（プロトタイプ）

WebClass 以外に出た課題も見落とさない、山形大学生のための締切通知サービスのプロトタイプです。
共創アントレプレナーシップⅣ 第4回「価値を検証する方法としてのプロトタイピング」の課題として作成しました。

- 公開ページ: https://takubon0202.github.io/co-creation-prototype-iv-linelms/
- 時間割のスクショとシラバスの URL を送ると、今週の締切をまとめて LINE に通知する、という体験を、画面を押しながら試せます
- 実際の登録や通知は行いません
